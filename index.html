What is IPLp?

IPLp predicts the probability that team1 wins an IPL T20 match. Two modes exist:

  • pre-match — teams, venue, date, plus historical strength (Elo, form, head-to-head).
  • match-day — same as pre-match, plus toss winner and toss decision (bat/field).

Output is always a calibrated probability, not a guarantee. Typical hold-out accuracy is ~52–58%.

Quick start (developers)

py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python -m ipl_predictor download-data --force
python -m ipl_predictor train pre
python -m ipl_predictor train matchday

Quick start (public users)

Use the hosted web app on the site branch deployment — no CLI, no CricAPI key. Enter teams, venue, date; optional toss fields for match-day mode.

See web-app and http-api.

System requirements

  • Python 3.11 or 3.12 (64-bit Windows/macOS/Linux)
  • ~500 MB disk for dependencies
  • Trained artifacts: artifacts/pre/model.joblib, artifacts/matchday/model.joblib

What IPLp does not do

  • Ball-by-ball live score prediction
  • Player-level fantasy points (XI hash features exist but are not in the default model)
  • Automatic 2025/2026 results without refreshing the dataset
  • Betting advice — educational/research use only

License & data

Match CSV is aggregated from public community sources (2008–2024). Team names and venues must match historical spelling for best results.
