HTTP API

FastAPI endpoints (site branch). No CricAPI required.

index architecture math data training http-api web-app

Run locally

pip install -r requirements-api.txt
set IPL_PROJECT_ROOT=C:\path\to\repo
uvicorn web.api.main:app --reload --port 8000

Open http://127.0.0.1:8000

GET /api/health

Returns whether pre and matchday model files exist.

GET /api/meta/teams

JSON list of team names from matches.csv (autocomplete).

GET /api/meta/venues

JSON list of venues from matches.csv.

GET /api/meta/dataset

Season range and row counts.

POST /api/predict/pre

{
  "team1": "Mumbai Indians",
  "team2": "Chennai Super Kings",
  "venue": "Wankhede Stadium, Mumbai",
  "date": "2024-05-12"
}

Response:

{
  "team1": "...",
  "team2": "...",
  "p_team1_win": 0.52,
  "p_team2_win": 0.48,
  "predicted_winner": "..."
}

POST /api/predict/matchday

Same body as pre, plus optional:

"toss_winner": "Mumbai Indians",
"toss_decision": "bat"

Errors

codemeaning
400Invalid date format
503Models or dataset missing on server
500Prediction failure (check team/venue spelling)
