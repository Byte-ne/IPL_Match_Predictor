Commands

python -m ipl_predictor train pre
python -m ipl_predictor train matchday

Each run overwrites artifacts/<mode>/model.joblib (~1–2 minutes on a laptop).

CatBoost defaults

parametervalue
depth6
learning_rate0.06
iterations1200 (early stopping on valid)
random_seed42

Metrics file

artifacts/pre/metrics.json example fields:

  • train.log_loss, valid.log_loss
  • train.brier, valid.brier
  • train.accuracy, valid.accuracy

When to retrain

  • After download-data --force
  • After changing feature code
  • Before deploying the web API with new artifacts

Deploying models to the web branch

Copy artifacts/ and data/raw/matches.csv to the server (or site-branch repo root) next to ipl_predictor/.
