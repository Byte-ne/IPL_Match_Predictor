What the model optimizes and how features are defined.

Prediction target

Binary label y = 1 if team1 wins, else 0. Model outputs p = P(team1 wins | x) with p ∈ (0,1).

Elo rating

Before each match, teams A and B have ratings R_A, R_B.

E_A = 1 / (1 + 10^((R_B - R_A) / 400))

After match:
R_A ← R_A + K * (S_A - E_A)
R_B ← R_B + K * (S_B - E_B)

S_A = 1 if A won else 0
K = 24 (default)

Features: elo_team1, elo_team2, elo_diff.

Rolling form

Win rate over the last N completed matches (default N=8):

form(team) = (wins in last N) / N

If fewer than N matches exist, average over available games. Default prior: 0.5.

Head-to-head

Win rate of team1 vs team2 over last M meetings (default M=10), computed before the current match.

Gradient boosted trees (CatBoost)

A sum of regression trees approximates log-odds of team1 winning. Categorical columns (team names, venue, city, toss fields) are handled natively. 

score(x) = Σ_t f_t(x)
p = σ(score) = 1 / (1 + exp(-score))

Loss function

Training minimizes log loss (cross-entropy):

L = -(1/n) Σ [ y_i log(p_i) + (1-y_i) log(1-p_i) ]

Calibration

Raw boosted scores are mapped with sigmoid (Platt-style) calibration fit on the time-based validation seasons so that, e.g., among matches assigned 70% probability, roughly 70% are team1 wins.

Why accuracy ≈ 55% is normal

T20 cricket has high variance (toss, form, injuries, conditions). Probabilistic models are judged by log loss and calibration, not raw accuracy alone.
