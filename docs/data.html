Default download

python -m ipl_predictor download-data --force

Fetches IPL matches 2008–2024 (~1090 rows) from a public GitHub CSV. Metadata written to data/raw/dataset_meta.json.

Canonical columns

columndescription
match_idUnique match identifier
seasonIPL year (e.g. 2024)
dateMatch date (ISO after normalization)
team1, team2Full franchise names
venue, cityStadium; city may be empty
toss_winner, toss_decisionOptional; bat/field
winnerWinning team name
resultno result / abandoned rows removed

Date formats

Parser accepts YYYY-MM-DD and DD-MM-YYYY (day-first). Mixed formats in one file are handled via pandas dayfirst=True fallback.

Custom CSV

python -m ipl_predictor train pre --raw-csv path\to\matches.csv

Column names are mapped automatically when they match common aliases (id, Team1, WinningTeam, …).

Inspect dataset

python -m ipl_predictor data-info

2025 / 2026 matches

The bundled URL stops at 2024. For newer seasons, merge a CSV with the same columns or replace matches.csv and retrain. Predictions for 2026 teams still use Elo/form state carried forward from 2024.
