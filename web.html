Purpose

End users predict matches in a browser. They do not need Python, CLI, or a CricAPI key. The server hosts trained models and the historical CSV for autocomplete.

Deploy (example)

  1. Train on main, copy artifacts/ + data/raw/ + ipl_predictor/ to host.
  2. Install requirements-api.txt.
  3. Start: uvicorn site.api.main:app --host 0.0.0.0 --port 8000
  4. Set IPL_PROJECT_ROOT to repo root on the server.
