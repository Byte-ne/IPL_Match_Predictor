Leakage safety

Elo and rolling features for match i are computed using only results from matches before match i in chronological order. The model never sees future outcomes when building features for training rows.

At inference time, ModelState stores ratings/form after the last training match (2024 in the default dataset). Live 2026 fixtures use that state as “current” strength.

Validation strategy

Last two IPL seasons in the CSV are held out for validation. All earlier seasons train the booster. Metrics in metrics.json refer to this split.
